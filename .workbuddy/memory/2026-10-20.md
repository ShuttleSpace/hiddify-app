## 关键技术决策与坑
1. **签名 JVM 必须用 DevEco JBR 25**：PATH 默认的 JDK 21 解析 hap zip64 extra 字段过严，报 `Invalid CEN header (invalid zip64 extra data field size)`；构建时需 `JAVA_HOME=/Applications/DevEco-Studio.app/Contents/jbr/Contents/Home` 且 JBR bin 置于 PATH 最前
2. **profile PEM 尾部换行**：`$(awk)` 命令替换吃掉行尾 `\n`，导致 hap-sign-tool 落入 base64 分支报 `Illegal base64 character 20`；python 内联脚本需显式补 `\n`
3. **.app 内嵌 hap 默认不单独签名**：需 `build-profile.json5` 的 `app.buildModeSet[release].buildOption.packOptions.appWithSignedPkg: true` 才会额外产出 `ohos-default-all-signed.app`（inner haps 已签，可直接安装）
4. 本地自签名材料（`ohos/signature/`）：generate-debug-signature.sh 生成统一密钥库 + 证书链 + p7b；generate-signing-material.js 复刻 hvigor 密码加密（PBKDF2+AES-GCM material 目录）；密钥库 .p12 已 gitignore
5. Rosetta 2 已安装（ohos-arm64 darwin-x64 gen_snapshot 需要）
6. 标准构建命令：
   ```bash
   export HOS_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk \
     DEVECO_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk \
     JAVA_HOME=/Applications/DevEco-Studio.app/Contents/jbr/Contents/Home \
     PATH="/Applications/DevEco-Studio.app/Contents/jbr/Contents/Home/bin:/Applications/DevEco-Studio.app/Contents/tools/ohpm/bin:/Applications/DevEco-Studio.app/Contents/tools/hvigor/bin:/Users/humphrey/.puro/envs/ohos/flutter/bin:$PATH" && \
   cd /Users/humphrey/Workspace/hiddify-app && flutter build app --release --build-name=5.0.0 --build-number=50000
   ```
