# FLClash 能力迁移到 Hiddify 的设计

## 背景与目标

本设计以 `/Users/ahs/Downloads/FlClash-main` 主分支快照为参考，评估将 FLClash 的网络统计、GeoIP、外观、备份和快捷操作能力迁移到 Hiddify 的方式。

迁移目标不是复制 FLClash 的设置页面和配置模型，而是在保持 Hiddify 信息架构清晰的前提下引入有价值的能力。业务模型必须跨 Windows、macOS、Linux、Android、iOS 和 Web 复用；托盘和系统级快捷键等平台能力仅在受支持的平台显示。

## 现状

Hiddify 已具备以下基础，不应重复实现：

- `StatsNotifier` 和核心统计流已提供实时上下行速度及会话累计量。
- 桌面系统托盘已支持连接状态、延迟、服务模式和连接切换。
- `AppThemeMode` 已支持跟随系统、浅色、深色和纯黑模式。
- `ShortcutWrapper` 已提供应用内快捷键框架，但部分动作尚未完成。
- Drift 已用于结构化持久化，可承载聚合后的历史流量和备份元数据。
- Android 已有应用快捷方式和快捷设置磁贴。

FLClash 的相关实现集中在 `AppSettingProps`、`ThemeProps`、`BackupAction`、`DAVClient`、`TrayManager` 和 `HotKeyManager`。其中部分能力可借鉴，但其单一大配置对象、较多低价值开关、可逆混淆密码和 Clash 专属配置不适合直接复制。

## 设计原则

1. 迁移能力，不迁移 FLClash 的设置表面结构。
2. 普通设置最多经过两层即可完成；专家项集中在明确标注的高级区域。
3. 已有能力优先增强，避免并行状态和重复数据源。
4. 领域接口跨平台，平台插件只负责能力适配。
5. 不支持的能力不显示入口，不展示无法工作的禁用设置。
6. 后台采集、网络请求和持久化不得影响代理连接的可靠性。
7. 密码、授权信息和订阅内容不得进入日志或普通偏好存储。

## 信息架构

Hiddify 的一级设置保持为六组：

| 设置组 | 内容 | 处理方式 |
| --- | --- | --- |
| 常规 | 启动、关闭行为、更新、语言 | 保留现有结构 |
| 连接 | 入站、DNS、路由、服务模式 | 保留现有结构，高级参数继续分层 |
| 流量与网络 | 实时速度、历史统计、统计范围、IP 和 GeoIP 检测 | 新增统一入口 |
| 外观 | 主题模式、主题色、文字大小、纯黑模式 | 合并为一个页面 |
| 备份与恢复 | 本地导出、WebDAV、自动备份、恢复 | 新增统一入口 |
| 快捷操作 | 应用内快捷键、桌面全局快捷键、托盘行为 | 按平台能力显示 |

## 架构与数据流

### 流量监测

核心统计流仍是唯一实时数据源：

```text
Core 实时统计流
  ├─ 当前界面：实时速度和会话累计
  ├─ 托盘适配：节流后的上下行速度
  └─ 统计仓库：按时间增量聚合后写入 Drift
```

新增领域模型：

- `TrafficSnapshot`：采样时刻、上传速度、下载速度和核心累计值。
- `TrafficSession`：连接开始、结束、上传量和下载量。
- `DailyTrafficUsage`：日期、上传量、下载量及可选配置 ID。
- `TrafficPreferences`：是否记录历史、保留周期和是否显示托盘速度。

实时采样不逐秒落库。统计服务每分钟或在连接结束时计算增量并更新日聚合记录。默认保留十二个月。核心重启、累计值回绕或配置切换时重新建立基线，不生成负流量。

托盘最多每秒刷新一次，格式未变化时跳过更新。关闭托盘网速后停止该消费者对统计流的订阅。

### GeoIP 与网络诊断

职责拆成两个模块：

- `NetworkIdentityService` 查询公网 IP、出口国家或地区、ASN 和代理状态。
- `GeoResourceRepository` 管理 GeoIP、GeoSite、MMDB 等本地路由资源。

资源记录包含类型、来源 URL、版本、更新时间、校验值和状态。资源先下载到临时文件，完成格式和校验验证后原子替换；失败时继续使用上一份有效资源。

网络身份查询使用可替换 provider、超时和缓存，不依赖单一公共接口。自动查询默认仅在连接成功后执行一次。自定义检测服务首次启用时说明其会看到用户的出口 IP。

### 外观

统一使用 `AppearancePreferences`：

- `themeMode`：跟随系统、浅色、深色、纯黑。
- `colorSource`：Hiddify 默认色、系统动态色、预设色。
- `seedColor`：预设或自定义模式使用的种子色。
- `textScaleMode`：跟随系统、小、标准、大、特大。
- `reduceMotion`：跟随系统或减少动画。

纯黑沿用 `AppThemeMode.black`，不引入“深色 + 纯黑开关”的无效组合。文本缩放在应用根节点统一应用，在合理上下限内基于系统无障碍缩放计算，不强制覆盖系统值。

### 备份与恢复

定义三个存储无关接口：

- `BackupArchiveService` 生成、读取和验证备份包。
- `BackupDestination` 对接本地文件、WebDAV 和未来的其他目标。
- `RestoreCoordinator` 负责预览、选择内容、执行恢复和回滚。

备份包使用 ZIP：

```text
manifest.json
preferences.json
profiles/
database.sqlite
database-export.json
metadata/
checksums.json
```

`manifest.json` 记录格式版本、应用版本、平台、创建时间和内容清单。SQLite 快照只用于同版本快速恢复；`database-export.json` 是跨版本迁移依据，避免数据库物理结构成为永久协议。

恢复流程先验证格式版本和校验值，再展示内容、时间、来源版本和冲突摘要。用户选择合并恢复或替换全部，也可选择设置、配置或订阅、路由资源元数据和流量历史。替换全部之前自动创建本地回滚包。

缓存、日志、已下载的 Geo 大文件和 WebDAV 密码默认不进入备份。WebDAV 凭据存入系统安全存储，普通配置只保存凭据引用。

### 快捷操作

共享层使用稳定动作标识，不依赖键盘或平台插件：

- 切换连接。
- 显示或隐藏窗口。
- 打开设置。
- 切换系统代理。
- 循环服务模式。
- 从剪贴板添加配置。

桌面提供应用内和可配置全局快捷键，并在保存前检测冲突。Android 将共享动作映射到应用快捷方式和快捷设置磁贴。iOS 为 App Intents 或 Shortcuts 预留适配接口。Web 仅启用应用内快捷键。

注册失败不影响应用启动；冲突只拒绝对应项目，不注销其他有效快捷键。

### 平台能力

使用只读 `PlatformCapabilities` 描述平台能力：

- `supportsTray`
- `supportsTraySpeedIndicator`
- `supportsGlobalHotkeys`
- `supportsSecureStorage`
- `supportsDynamicColor`
- `supportsFileExport`
- `supportsBackgroundBackup`

设置页面根据能力决定是否显示项目。共享领域层不散布平台判断，平台差异收敛到适配器。

## 页面交互

### 流量与网络

- 顶部展示当前上传、下载和本次连接累计量。
- 历史统计支持日和月视图，不提供 Dashboard 编辑。
- 网络信息卡片展示公网 IP、地区、ASN 和检测时间。
- 路由资源默认只显示健康状态和更新时间；来源及周期放入高级区域。
- 桌面受支持平台显示“在托盘显示实时网速”。
- 清除历史流量需要确认，并明确不可恢复。

### 外观

- 第一层只显示主题模式、主题色和文字大小。
- 调整后即时预览并保存。
- 纯黑是主题模式之一，不是附属开关。
- 文字大小使用五个语义选项并展示预览文本。
- 动态色仅在支持的平台出现。

### 备份与恢复

- 本地备份和 WebDAV 使用独立卡片。
- 首页显示最近备份结果、立即备份和恢复。
- WebDAV 连接信息在二级页面编辑。
- 选定恢复包后必须先展示内容和冲突摘要。
- 替换全部使用高风险确认并先创建回滚包。
- 自动备份默认关闭；开启后默认每周一次，仅在平台后台条件允许时运行。

### 快捷操作

- 应用内快捷键与桌面全局快捷键分组。
- 每行显示动作、组合键和恢复默认操作。
- 移动端只展示可用的系统入口说明，不显示键盘录制控件。
- 禁止仅使用字母、数字或系统保留组合。

## 错误、隐私与恢复

- 统计流中断时显示暂不可用，不将零值写入历史。
- 流量落库失败不影响代理连接，记录脱敏诊断并延迟重试。
- GeoIP 查询失败时保留上次结果和检测时间。
- Geo 资源验证失败时保留旧文件，不使用半下载文件。
- WebDAV 错误区分地址、认证、权限、超时和证书问题。
- 恢复失败时停止后续步骤并报告自动回滚结果。
- 日志不得记录 WebDAV 密码、授权头、完整订阅或敏感备份字段。

## 验证策略

- 单元测试覆盖流量增量、日期聚合、累计回绕、备份清单、校验和、格式兼容、Geo 资源原子替换和快捷键冲突。
- Drift 迁移测试验证从当前 schema 升级且保留现有数据。
- Provider 测试覆盖统计流断开和恢复、设置持久化及平台能力过滤。
- Widget 测试覆盖设置入口、恢复预览、危险操作确认和能力相关显示。
- Windows、macOS 和 Linux 验证托盘、全局快捷键与文件导入导出。
- Android 和 iOS 验证文件选择、分享或导出、安全存储及文字缩放。
- Android 额外验证快捷设置磁贴和应用快捷方式不回归。
- 固定备份样本覆盖旧版本、损坏包、缺少可选内容和未知字段。

## 分阶段交付

1. **基础模型与外观**：平台能力、统一外观设置、文字缩放和主题色。
2. **流量与托盘**：历史流量数据库、聚合服务、统计页面和托盘速度开关。
3. **GeoIP 与路由资源**：网络身份服务、资源状态和安全更新；实现前确认 hiddify-core 的资源接口边界。
4. **本地备份与恢复**：版本化备份包、恢复预览、合并、替换和回滚。
5. **WebDAV**：安全凭据、连接检测、远端上传下载和可选自动备份。
6. **快捷操作**：共享动作注册表、应用内快捷键修复、桌面全局快捷键和移动端动作映射。

每个阶段独立提交、独立测试，后续阶段未完成不阻止已完成能力启用。

## 明确不在范围内

- 复制 FLClash 的 Dashboard 自由编排。
- 复制 Clash 专属配置、脚本、覆写和代理组样式。
- 将下载后的 Geo 资源大文件默认上传到备份目标。
- 在不支持托盘或全局快捷键的平台显示占位设置。
- 将 SQLite 物理文件格式作为唯一、永久的备份兼容协议。
